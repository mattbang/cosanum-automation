# Cosanum Training Automation

A prototype for coordinating logistics training with Google Workspace. It is designed to cover training requests, calendar scheduling, trainer assessment, individual acknowledgement, evidence archiving, and skill records.

The [public project overview](docs/PROJECT_OVERVIEW.md) describes the goal and technology. The [development plan](docs/DEVELOPMENT_PLAN.md) breaks delivery into small, testable increments. This repository starts with planning material; the connected prototype will be developed one verified feature at a time.

The detailed planning specification, real source documents, test-account details, and training evidence are kept outside the public repository. Demo records will be marked clearly and stored in a local archive with a matching Google Drive copy.
