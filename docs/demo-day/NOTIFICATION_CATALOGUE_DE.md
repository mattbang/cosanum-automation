# Nachrichten je Prozessschritt

Stand: 29.10.2026 · synthetische Site. Diese Tabelle liefert die konkrete Vorführsprache und die Nachrichten, die eine spätere Integration senden könnte. Nur die Einladung hat heute einen befüllten manuellen Mailentwurf. Andere „Betreff“- und „Text“-Felder sind vorgeschlagene Nachrichtentexte für die Präsentation; die aktuelle Site zeigt dazu Status, Hinweise und Verlauf. Es gibt keinen automatischen Mailversand, keine zeitgesteuerten Mails und keinen Hintergrund-Push. Kein Versand wird durch dieses Dokument ausgelöst.

Platzhalter: `{Thema}`, `{Zielniveau}`, `{Angebote_Zürich}`, `{Termin_Zürich}`, `{Materiallink}`, `{persönlicher_Teilnehmerlink}`, `{Raumansicht}`. Diese stehen für synthetische Fallwerte. Persönliche Links und Kontoadressen werden weder hier noch in öffentlichen Screenshots eingetragen. Der Rollenlink von Daniel bleibt von Matthews Zugang getrennt.
