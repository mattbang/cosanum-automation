# Veröffentlichungsprotokoll der Statusberichte

Ein Eintrag entsteht erst nach dem bestätigten Teams-Beitrag. Vor einem erneuten Versand nach einem Fehler direkt im privaten Teams-Kanal prüfen, ob bereits ein Beitrag für dieselbe GitHub-Archivfassung vorhanden ist. Dieses Protokoll liegt im öffentlichen Repository: keine Testkonto-Adressen, privaten Belege, Teams-Beitragslinks oder internen Beitrags-IDs eintragen.
