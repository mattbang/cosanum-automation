# UX2 public tour and feedback handoff

The public starting page is [`docs/demo-tour/index.html`](demo-tour/index.html). `docs/index.html` routes the GitHub Pages `/docs` site to it. The page now presents a synthetic Monday–Friday week, role-only availability, common free slots for the selected trainer and participants, and a five-step preview of role-labelled emails. Selecting a slot or advancing a step changes only browser state. The optional visitor email is shown only in the preview; the page makes no network request, sends no mail, and stores no address. Dates, busy blocks, trainer reports, confirmations, and results are illustrative. Group training with several participants uses Process & Quality as trainer; a one-person group may choose HCM4.

A request link may supply `request`, `scenario`, and a Google Forms feedback URL. Invalid values are ignored. No participant case or admin action URL appears in the page. In the owner-only Demo Hub, **Startlink vorbereiten** creates or reuses the feedback Form in the dedicated demo folder and builds the group starting link. Process & Quality retrieves only that request's feedback in **Ergebnisse & Register**. Feedback is not a training completion record. The private functional demo still uses assigned Calendar invitations and verified-email training Forms.

GitHub Pages serves `https://mattbang.github.io/cosanum-automation/demo-tour/` from `feature/demo-final` / `docs`. Keep this source branch and URL stable when updating the shared Teams link. Do not share the owner-only admin URL or owner password. The feedback Form may accept comments from anyone with its link; comments are not evidence and never update cases.

Local check: `node scripts/test_demo_tour.mjs` covers URL validation, next-week date calculation, shared-slot filtering, no-write source, and owner-only feedback association. Browser QA should check desktop and phone widths, role changes, slot selection, and all five preview stages. Actual self-service email requires a separate sending service with address confirmation and send limits; the static page cannot provide it.
